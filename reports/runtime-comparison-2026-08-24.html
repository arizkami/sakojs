    Interpretation limits

    • One local machine and one run cannot establish universal rankings.
    • Startup includes PowerShell process launch and output-capture overhead.
    • File reads use a warm operating-system cache; they do not measure storage latency.
    • HTTP uses the shared node:http API and loopback traffic, not each runtime's fastest native server API.
    • Server memory is an idle snapshot after readiness, not peak memory during load.
